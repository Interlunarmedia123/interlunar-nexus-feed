# Nexus Feed

Weekly reading page for Interlunar Media: Meta &amp; Google Ads changes, marketing AI tools, and industry news. Curated by Nexus, hosted on GitHub Pages.

Live at: https://interlunarmedia123.github.io/interlunar-nexus-feed/

- `index.html` - current issue (overwritten each week)
- `issues/YYYY-MM-DD.html` - permanent archive of each issue
- `archive.html` - list of past issues

Feedback loop runs through Slack, not on-page marking - reply to the weekly digest to steer what shows up next.
